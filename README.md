# 🎨 Neural Style Transfer

A **Neural Style Transfer** web application built with **PyTorch and Flask** that combines the content of one image with the artistic style of another using **Adaptive Instance Normalization (AdaIN)**.

## ✨ Features

* Upload content and style images
* Generate artistic images using AdaIN
* PyTorch-based deep learning model
* Simple Flask web interface
* GPU support with CUDA
* Responsive image processing

## 🛠️ Technologies

* Python
* PyTorch
* Torchvision
* Flask
* Pillow
* NumPy
* WTForms
* Gunicorn
